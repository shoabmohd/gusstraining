# SpaceX Launch Records Dashboard

Completed solution for the IBM Skills Network / Coursera Plotly Dash lab.

## Files
- `SpaceX_Dashboard_Lab_Solved.ipynb` — guided notebook with all four tasks and analysis cells.
- `spacex_dash_app.py` — runnable interactive dashboard.
- `requirements.txt` — Python dependencies.
- `screenshots/` — location for screenshots captured from the running dashboard.

## Run locally
```bash
python -m pip install -r requirements.txt
python spacex_dash_app.py
```
Open `http://127.0.0.1:8050`.

If automatic dataset download is blocked, download `spacex_launch_dash.csv` from the IBM lab and place it beside `spacex_dash_app.py`.

## Screenshots
Capture the live app after running it and save `dashboard_all_sites.png`, `dashboard_selected_site.png`, and `dashboard_payload_filter.png` in `screenshots/`. They are not generated here because screenshots must reflect the running application.
